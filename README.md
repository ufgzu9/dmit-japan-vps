# 日本 VPS 購買：東京 CN2 GIA 與國際線路怎麼挑，DMIT 全方案價格、流量限制與優惠碼整理

買日本 VPS 的理由通常只有兩個：一來離台灣、香港、華東華南都近，二來需要一個日本原生 IP。但實際下單時，多數人卡住的地方不是配置，而是線路——同樣標「日本東京」，有的是三網 CN2 GIA 回程，有的走的是純國際互聯，價格可以差到好幾倍，用起來的體感差距也一樣大。

這篇用 DMIT 的東京機房（TYO）當實際案例，把線路、方案、價格、流量規則和優惠碼一次講清楚。DMIT 是 2017 年前後開始營運的海外 VPS 服務商，機房在美國洛杉磯、中國香港、日本東京三地，東京節點用的是 AMD EPYC 平台加 NVMe SSD，付款支援支付寶、PayPal 和信用卡。選擇它來說明，是因為它把東京機房切成了定位完全不同的產品線，拿來對照最直觀。

## 先回答一個問題：你的訪客在哪裡

這個問題決定你該花 $6.9 還是 $21.9。

如果主要訪問人群在中國大陸，尤其是電信用戶，那你要買的是優化線路，預算抓每月 20 美元起跳是合理的，低了買不到真正的 CN2 GIA。如果你的業務面向日本本地、東南亞，或者只是拿來跑備份、爬蟲、離線任務、自建中轉，那純國際線路的方案便宜一半以上，甚至年付不到 40 美元就能拿到一台。

把需求講清楚，後面所有的價格比較才有意義。

## CN2 GIA、CMI、國際線路，差別不是行銷話術

DMIT 東京目前可買的產品線主要是兩條，外加一個限量款。

**Premium（TYO.Pro）** 走三網優化：回程 CN2 GIA（電信）/ AS9929 精品網（聯通）/ CMI（移動），去程同樣做過優化。這是日本機房裡線路最頂的一檔，延遲和晚高峰穩定性表現最好，代價是價格。測試 IP 是 154.12.190.32。

**Tier 1（TYO.T1）** 是純國際互聯，官方不承諾對中國大陸的直連品質。路由上電信、聯通雙程走 NTT，部分線路會繞美國 Lumen，移動則走 CMI。測試 IP 是 154.31.112.5。它的定位不是「便宜版 Pro」，而是另一種用途：落地節點、面向日本或國際用戶的站點、對大陸速度沒硬需求的專案。

另外還有一個 **Eyeball（TYO.EB）** 系列，主打三網 CMI 回程，對移動用戶更友善。但從 2025 年底到 2026 年初的多個來源都提到這條產品線已經下架或缺貨，官網查不到。如果你在別的地方看到 EB 的價格表，先確認一下是不是舊資料。

實際測試延遲和路由，可以自己去看官方提供的 Looking Glass（lg.dmit.sh），比看任何評測都直接。

## 付款、退款與 IP 更換：下單前要知道的三件事

**付款方式**：支付寶、PayPal、信用卡都支援，對華語用戶來說流程不複雜。

**退款政策**：3 天內且流量使用不超過 30GB 可全額退款；一個月內按剩餘價值退款，但會扣除支付網關費用。也就是說，買回來測一輪延遲和速度，不行就退，這個窗口是存在的，但有流量門檻。

**IP 更換**：IP 被牆的情況下，每 15 天可以免費更換一次 IP。注意部分特殊促銷（例如歷史上的 5 折年付活動）會限制 IP 更換頻率並收取費用，買之前看清楚活動條款。官方文件在 docs.dmit.io 上可以查。

## 常見問題

**日本 VPS 一定要買 CN2 GIA 嗎？**

看你訪客在哪。主要用戶在中國大陸而且在意晚高峰體驗，值得買。面向日本本地或者東南亞業務，T1 的 NTT 國際路由完全夠用，價格低一個量級。

**Pro 和 T1 的流量規則差在哪？**

Pro 用完暫停，T1 用完限速不停機。這是兩個系列在用途上最實際的分界線，比線路參數更影響日常使用。

**Pro 系列經常缺貨，值得等嗎？**

從 2025 年到 2026 年，Pro 系列一直是斷斷續續補貨的狀態，補貨原因通常是釋放出一批可用 IP，補完很快又沒了。如果你已經確定要 Pro，看到有貨就別拖太久。

**可以拿來做什麼？**

三網優化的 Pro 適合企業站、跨境電商、API 服務、遠端辦公、對延遲敏感的工具類應用；T1 適合備份、爬蟲、離線任務、面向非大陸用戶的站點。串流解鎖這一項，官方沒有給出承諾，不同 IP 段表現不一樣，不建議當成購買理由。

**價格會漲嗎？**

會，而且已經漲過。2026 年整個行業的優化線路都在漲價或下架部分產品，DMIT 也不例外。所以看到任何價格表，都要記得它只代表記錄當時的狀態。
